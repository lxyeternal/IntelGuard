The SCS team has been closely monitoring a threat actor under the label PYTA31, in a recent attack detected by our ML power engine. PYTA31 was found distributing the “WhiteSnake” malware. This attack was also reported a few days ago by JFrog’s security researchers.
In the past few days, our obfuscation detection engine successfully uncovered several additional packages linked to this threat actor. Some of these packages remain accessible on the PyPI repository posing a potential risk to unsuspecting users.
Dissecting the Malicious Payload
The malicious code was embedded inside the package, base64 encoded, which also allowed the attacker to ship the binary within the code. After installation on the victim’s machine, the OS-specific code executes the corresponding payload. On Linux-type OS an exec command executes a simple python script, whereas, on a Windows-type machine, a more complex “WhiteSnake” malware executable is created and executed.

Conclusion
Our ML engine successfully revealed and thwarted part of the malicious “WhiteSnake” campaign. This incident highlights the critical need for vigilance when it comes to open-source packages. While PyPI and other package managers offer valuable resources for developers, it is essential to vet any package thoroughly before implementing it in your projects.
Moreover, investing in robust security measures, like our machine-learning malicious obfuscation detection engine, can help identify and neutralize potential threats before they wreak havoc. Don’t wait for the next attack; take action now to secure your software supply chain and protect your valuable data.
