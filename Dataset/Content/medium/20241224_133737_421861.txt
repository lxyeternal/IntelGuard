In April, the open-source community experienced several notable events. New revelations continued to emerge about the 3CX DesktopApp supply chain attack, Checkmarx’s Machine Learning obfuscation detection engine uncovered activities of threat actor PYTA31, and NPM has been targeted by a new stealthier type of Typosquatting. Additionally, we introduced the Developer Entity Behavioral Analysis (DEBA) engine and showcased our innovative retro-hunting system.
Let’s delve into some of the most striking events of April:

New revelation of the 3CX attack reveals a cascade of supply chain attacks
The 3CX DesktopApp supply chain attack, orchestrated by the North Korean-backed hacking group UNC4736, has now affected critical infrastructure organizations and potentially many more. This rare and sophisticated cascading software supply chain attack began with an employee’s personal computer, which was compromised after downloading a trojanized version of Trading Technologies’ X_TRADER software, which it itself had been affected by a separate supply chain attack. The full extent of the damage is yet to be uncovered. (report)
ML engine detects Pypi packages containing Whitesnake malware designed to steal personal data
Threat actor PYTA31 distributed “WhiteSnake” malware through malicious PyPI packages, targeting victims’ sensitive data. The malware executes OS-specific payloads and uses obfuscation and evasion techniques, making it challenging for researchers to analyze. (report)
A new stealthier type of Typosquatting attack spotted, targeting npm
NPM’s package naming history has left it vulnerable to an impersonation attack, where bad actors upload malicious packages that consist of the exact same letters as currently available legitimate ones, using lowercase letters to mimic original uppercase letters. This stealthier form of “Typosquatting” is harder for users to spot and impacted 1,900 packages on NPM, totaling over 500,000 weekly downloads. Shout out to the NPM security team, who quickly recognized and resolved the issue the moment we brought it to their attention. (report)
Developer Entity Behavioral Analysis (DEBA) engine
The Developer Entity Behavioral Analysis (DEBA) engine, offered by Checkmarx, combats account takeovers by consistently monitoring behavioral patterns across GitHub and package manager platforms. This proactive solution provides an additional layer of protection for the open-source community. (report)
Why we need to collect everything: retro-hunting in open source
While the open-source ecosystem enables rapid software development and collaboration, it also presents security challenges due to attackers infiltrating the supply chain with malicious packages. When package managers delete malicious packages, they inadvertently remove crucial information that could assist defenders in comprehending the scope of the threat and learning from attackers’ methods which could also prove invaluable in preventing similar future attacks. Addressing the limitations of merely reporting on detected malicious packages within the open-source ecosystem, Checkmarx’s retro-hunting system emerges as a comprehensive solution for safeguarding against open-source security threats. (report)
