StepSecurity Supply Chain Goat follows the tradition of existing *Goat projects. It provides a training ground to practice implementing countermeasures specific to the software supply chain.
StepSecurity defines a supply chain attack as an attack that tries to hijack software that you produce or consume.
Supply Chain Goat is an open-source GitHub repository to document past software supply chain attacks, and do a hands-on walkthrough of StepSecurity solutions that could have prevented them.
image: D:/Desktop/malware/IntelliGraph\Dataset\Image\medium_recommand\20241224_132336_841232\1dfgiKoxfnFeva1_DghTVmQ.png
Each countermeasure has a simple self-paced hands-on tutorial that you can complete in a few minutes using GitHub Actions. All you need to follow the steps is a GitHub account. No registration is required.
There is also a weekly free online Instructor-led training session. Each session is limited to 10 participants. Reserve a place for a session here.
