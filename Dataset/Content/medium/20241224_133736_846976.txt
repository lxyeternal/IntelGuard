In September 2023, the open-source community faced a wave of sophisticated supply chain attacks, underscoring the evolving sophistication of malicious actors. Hundreds of GitHub repositories were compromised as attackers impersonated GitHub’s trusted Dependabot, to commit malicious code into their target’s repos.
Simultaneously, the Python ecosystem endured relentless attacks. Unidentified threat actors exploited the platform for crypto-theft and data exfiltration, capitalizing on the trust within the community. Among these, a particularly persistent perpetrator stood out, having operated for months. Their modus operandi involved continuously refining malicious packages, maximizing impact, and proving the nefarious adaptability of these cyber adversaries.
Let’s delve into some of the most striking events of September:
When Dependabot Contributes Malicious Code
A sophisticated attack on GitHub repositories was discovered, involving suspicious commits appearing to be from Dependabot but were actually created by malicious actors. These actors exploited stolen GitHub personal access tokens to bypass 2FA security to carry out these commits. (report)

Evolution of a Persistent Threat
Beginning in April 2023, a persistent attacker infiltrated the Python ecosystem, and consistently uploaded malicious packages, increasing their complexity over time, achieving approximately 75,000 downloads. The malware targeted Windows systems, stealing extensive data and redirecting cryptocurrency funds to the attacker’s wallet. Financial analysis revealed significant gains for the attacker. (report)

Users of Telegram, AWS, and Alibaba Cloud Targeted in Latest Supply Chain Attack
A targeted cyberattack occurred in the PyPi ecosystem, focusing on developers using Alibaba Cloud services, AWS, and Telegram. The attacker employed an unconventional and stealthy approach by hiding malicious code within specific functions to avoid detection. Techniques such as Typosquatting and Starjacking were used to deceive developers into downloading the malicious packages. (report)

Attacker Unleashes Stealthy Crypto Mining via Malicious Python Package
A malicious Python package has been discovered, exploiting system resources for unauthorized cryptocurrency mining. The package uses obfuscated code and random filenames to avoid detection and runs an infinite loop to continue mining. The code has been traced to an active GitLab account, posing an ongoing risk. In addition to mining, the package connects to hardcoded pool URLs and wallet addresses, turning affected computers into part of an unauthorized mining operation. (report)
