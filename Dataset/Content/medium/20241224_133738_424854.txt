Additional findings came to light in a post-mortem investigation of a recent crypto miner attack on PyPi and npm. These findings bring this incident's total number of malicious packages to over a thousand, including a simple implementation of ransomware functionality.
As a quick recap, on August 18th, researcher Hauke Lübbers and Checkmarx’s SCS team had already been tweeting about the PyPi user account “32024193” while it was uploading over 60 malicious packages. These packages used both typosquatting and StarJacking techniques to lure developers into installing their packages, which download crypto miners upon installation from 80.78.25[.]140
The packages were removed from the PyPi registry (very) swiftly.
Shortly after, researchers from Sonatype were able to connect this incident to a similar one, only this time occurring on the npm registry and carried out by the user account “17b4a931.”
While looking at these findings, we run a retro search on our database and found:

The total number of packages uploaded by the npm user account 17b4a931 is over 900. Many of these seem to be typosquatting attempts targeting popular packages.
Some of the packages had an additional maintainer, the xwlazssz user account, which had more than 20 malicious packages uploaded and by now deleted from the npm registry.
The packages owned solely by xwlazssz exhibited ransomware functionality but still had the same comment as the ones published by 17b4a931
The attacker used the legitimate service beeceptor.com to retrieve what seems to be the encryption keys and ransom notes. The endpoints used are no longer available.
