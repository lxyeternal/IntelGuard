A few hours ago, the PyPi team announced that they are temporarily suspending the creation of new users and the publication of new projects after detecting a high volume of malicious activity that they are unable to respond to in a timely fashion.
Large-Scale Attack Trend
In the past few months, we have witnessed actors publishing overwhelming amounts of malicious packages in several open-source registries; among these is the NPM incident early last month that flooded the JavaScript package manager and caused a sporadic denial of service. Late last year, we saw a similar incident on the Nuget package manager, which included over 140,000 malicious packages.
Just last week, we saw a spike in package publication on PyPI.
Example: OaxStealer
Just today we saw an actor using 3 different user accounts to publish dozens of malicious packages designed to steal users’ data.
This package contains encoded code that, upon execution downloads a second piece of malware hosted on a legitimate service (replit.com)
The downloaded malware is designed to steal the victims information, including credentials, file names, screenshots etc.
Using Legitimate Service as C2
To implement the C2 collecting the stolen information, the attackers used the legitimate SaaS “replit, " which allows its users to write and run code online.
looking into the attacker’s account, we were able to find the full code of the C2 server and the .exe files used in the attack
The Big Picture
Zooming out of this specific incident, we can see that this abuse isn’t specific to PyPi and would like to continue and increase soon.
Hence, we must change the mindset from detecting attacks to identifying attackers.
Only by understanding the attackers' TTPs and raising the bar will we succeed in keeping the open-source ecosystem safe.
This will require the open-source ecosystem to develop new infrastructure and invest more in sharing attack data.
We are grateful for the work done by the PyPi team and believe the industry should better support their efforts which enable the open-source ecosystem to thrive.
Developers and organizations looking to invest in the right frameworks, we encourage you to look at OpenSSF S2C2F and community projects such as the Overlay extension.
Working together to keep the open source ecosystem safe.
