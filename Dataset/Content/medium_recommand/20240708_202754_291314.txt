Manifest Confusion — “massive bug at the heart of the npm ecosystem” reported by Darcy Clarke, former NPM Engineering Manager last month.
NPM open-source packages published by their contributor contain the code artifact archive and manifest file.
The manifest file displays information describing the artifact archive attributes such as bundled scripts, licenses, and other dependencies.
NPM does not verify the package’s manifest across the artifact archive file content.
NPM indexes and displays the content only from the manifest file but upon installation the archive file’s instructions are being executed.
Threat actors can hide malware in dependencies and scripts that go undetected.
We scanned packages published to NPM in the past year and found ~100K packages having manifest confusion differences.
