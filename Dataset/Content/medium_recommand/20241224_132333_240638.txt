New vulnerabilities in containers are discovered daily, and it’s crucial to patch these vulnerabilities promptly to protect applications from potential attacks. There are great companies like Chainguard who provide paid services to automatically patch your container images for you, or even provide a handful of container base images for free (see: https://images.chainguard.dev/), but what if you need to build your own custom images?
This blog post will guide you through setting up an automated system on MacOS for container vulnerability scanning and patching using copa (container patching automation) and trivy(a vulnerability scanner) tools that are under Cloud Native Computing Foundation governance.

copa CLI tool is an open-source project (https://github.com/project-copacetic/copacetic) that can be used with pluggable vulnerability scanners such as Trivy or Grype and automatically patch and build provided container images based on vulnerability reports.

Some prerequisites are required to use automated container patching system:
