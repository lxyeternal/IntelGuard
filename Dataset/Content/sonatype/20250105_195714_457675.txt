
Our research indicates that the Analytics feature in Sonatype Nexus Repository is rarely used and in certain instances, scalability issues arise when it is turned on. Therefore, we have decided to phase out the Analytics feature in a future version of Sonatype Nexus Repository.
image: D:/Desktop/malware/IntelliGraph\Dataset\Image\sonatype\20250105_195714_457675\blog20analytics20deprecated.png

As of version Sonatype Nexus Repository 3.14.0, the feature will still be available. However, it will automatically be disabled if you are using clustering in Sonatype Nexus Repository.
We have not determined when the feature will be removed entirely, however between now and then users should not start using it.
