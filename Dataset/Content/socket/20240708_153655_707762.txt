
We're always listening to our users, and based on the feedback we've received, we're making some updates.
Starting Friday, February 16, 2024, we're transitioning all Socket reports to the new Socket v1 Project Reports. This will give all users a more intuitive and efficient user interface, as these reports load significantly faster.
image: gjj_images\socket\20240708_153655_707762\033ebd725b53952c0c7323c5a88d72b53cefbae6-1600x797.png
This update means the old v0 links will no longer be active, and you'll be redirected to the improved v1 UI when accessing reports, whenever possible.

Links to /dashboard/org/gh/{org_name}/report-run/{id} (authenticated report links) will redirect to the new Socket Project Report v1 UI.
Links to /npm/reports/{hash} (unauthenticated report links) will now return a 404 error.
Additionally, Socket for Github will leave comments and create PR check runs using the new v1 link format: /dashboard/org/gh/{org_name}/sbom/{id} .
Whether you're using Socket for Github, Socket API, or Socket CLI, you'll notice the change with the new, user-friendly links. In the API, the url field returned as part of the report object in the API will use the new Socket Project Report v1 links.
This upgrade is all about making your interactions with Socket smoother and more productive. Please reach out if you have any questions or concerns.
