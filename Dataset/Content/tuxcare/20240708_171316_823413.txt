
Zorin OS 16.3 has arrived just nine months following the release of Zorin OS 16.2. This latest version incorporates all the recent updates from the upstream Ubuntu repositories, making it an ideal choice for users looking to install the most up-to-date Zorin OS 16 series on new computers.

Zorin OS 16.3: New Features
Zorin OS Upgrader
The most anticipated tool, Zorin OS upgrader, has been finally introduced in this version. This feature makes it easier for users to upgrade to new Zorin OS releases without reinstalling the system. For example, you can now easily upgrade Zorin OS 16 Core to Pro or Zorin OS 15 to 16 without losing your files, apps, and settings.
Zorin OS Upgrader
Zorin Connect app for Android received many improvements to ensure a seamless cross-device experience:

Execute commands on your computer effortlessly through the power menu on Android 11+.
Enjoy extended playback controls while using Spotify on your computer.
Automatically and discreetly reconnect to trusted networks in the background, available for Android 10+ users.
Embrace the themed monochrome icon, beautifully designed for Android 13+.
Benefit from improved translations for a more globally accessible experience.
Discover several quality-of-life enhancements thoughtfully integrated throughout the app.
Latest LibreOffice
LibreOffice 7.5 has been added, which includes many improvements, such as better compatibility with Microsoft Office/365 documents, significant improvements to dark mode, revamped tabbed navigation interface, filter documents by type, and more.
Other Changes and Improvements

Built-in support for Flatpak, AppImage, and Snap packages
Updated applications
Better security, compatibility, and performance
Conclusion
Zorin OS 16.3 runs on the Linux kernel 5.15 LTS from the Ubuntu 22.04 LTS (Jammy Jellyfish) operating system series. Interested users can download Zorin OS 16.3 immediately from the official website, available in Core, Lite, Education, and Pro editions. It’s worth noting that the Zorin OS 16 series will continue receiving official support, including software updates and security patches, until April 2025, ensuring a stable and reliable user experience.
