
Multiple vulnerabilities in Python have been identified and patched, with updates available for several Ubuntu releases, including Ubuntu 24.04 LTS, Ubuntu 22.04 LTS, and Ubuntu 20.04 LTS. These vulnerabilities pose serious security risks, such as denial of service (DoS) and the ability to bypass protection mechanisms.
In this article, we will explore the latest Python vulnerabilities, how they impact systems, and what steps you can take to secure your environment.

Python Vulnerabilities Details

CVE-2023-27043
In Python versions up to 3.11.3, the email module incorrectly parses email addresses containing special characters. This leads to the wrong part of an RFC2822 header being identified as the addr-spec value. As a result, attackers could potentially bypass security mechanisms in applications that grant access based on email verification to a specific domain (e.g., only allowing addresses from @company.example.com for signup). This vulnerability originates from the email/_parseaddr.py file in recent Python versions.

CVE-2024-6232
A MEDIUM severity vulnerability has been identified in CPython, where regular expressions used in tarfile.TarFile header parsing allow excessive backtracking. This makes the module vulnerable to Regular Expression Denial of Service (ReDoS) attacks through specially crafted tar archives.

CVE-2024-6923
A MEDIUM-severity vulnerability has been identified in CPython’s email module. When serializing an email message, the module failed to properly quote newlines in email headers, potentially enabling header injection attacks. A header injection is a technique that allows the modification or insertion of unauthorized email header fields, potentially resulting in malicious activities such as spoofing or phishing.

CVE-2024-7592
Another vulnerability exists in CPython’s http.cookies standard library module. When parsing cookies with backslashes in quoted values, the parser could experience quadratic complexity, leading to excessive CPU usage and potential denial-of-service (DoS) attacks.

CVE-2024-8088
This vulnerability was discovered in the CPython zipfile module’s zipfile.Path class. While the more commonly used zipfile.ZipFile class is unaffected, iterating over entry names in a maliciously crafted zip archive (using methods like namelist(), iterdir(), etc.) can lead to an infinite loop. This vulnerability affects both metadata reading and content extraction, potentially causing denial-of-service (DoS) attacks. Programs that do not handle user-controlled zip archives are not at risk.

How to Protect Your Systems

It is essential to update your Python packages immediately to ensure your system is protected against these vulnerabilities. Canonical has already released patches to address these security flaws across its supported versions of Ubuntu.
Ubuntu users can easily apply the latest security patches using the apt package manager. Running the following commands will help you upgrade to the most secure version of Python:
sudo apt update
sudo apt upgrade python3
After the update, you should confirm the version of Python installed by running:
python3 --version
