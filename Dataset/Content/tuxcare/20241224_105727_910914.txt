
As per media reports, Mozilla has recently uncovered a critical Firefox Zero-Day flaw impacting both the browser and the Extended Support Release (ESR). Reports claim that this Firefox zero-day flaw has been exploited in the wild. In this article, we’ll dive into the vulnerability, affected versions, and protection measures against it. Let’s begin!
The Firefox Zero-Day Flaw Uncovered
The Firefox flaw that Mozilla has recently revealed is being tracked as CVE-2024-9680. It has a critical vulnerability severity score (CVSS) of 9.8 and is a use-after-free bug within the animation timeline component.
The bug was initially discovered and reported by security researcher Damien Schaeffer from a Slovakian company called ESET. Given the severity of this Firefox zero-day flaw, prompt mitigation and protection measures were taken, and it has been addressed in:

Firefox 131.0.2.
Firefox ESR 128.3.1.
Firefox ESR 115.16.1.
Understanding Use-After-Free Vulnerabilities
While the Firefox zero-day flaw has been addressed in the version mentioned above, understanding what user-after-free vulnerabilities are is essential for ensuring protection in an evolving threat landscape. These flaws are basically memory bugs that occur when dynamic memory is not used correctly during a program’s operations.
Such bugs reuse memory locations after freeing them, which allows hackers to inject malicious data into the memory location and execute code. This allows threat actors to utilize remote code execution flaw, like the Firefox zero-day flaw, in several initiatives like:

Conducting a watering hole attack on a website.
Exploiting them via drive-by download campaigns.
Given these adverse attack scenarios and results, users are urged to update to the latest version. Doing so is essential for mitigating risk and helps improve the overall security posture.
Tor Browser Exploits And Mitigation Protocols
The Tor project, alongside Mozilla’s advisory on the Firefox zero-day flaw, has also released an emergency update to the Tor browser. The update, version 13.5.7, also addresses CVE-2024-9680, which has been actively exploited. The emergency release from Tor states that:
“Update Tor Browser to 13.5.7, which fixes MFSA 2024-51, a major use-after-free vulnerability. Using this vulnerability, an attacker could take control of Tor Browser, but probably not deanonymize you in Tails. Mozilla is aware that “a Firefox exploit that had been spotted in the wild.”
Mozilla in a separate blog post, in addition to the security advisory pertaining to the Firefox zero-day flaw, has stated that:
“The sample ESET sent us contained a full exploit chain that allowed remote code execution on a user’s computer. Within an hour of receiving the sample, we had convened a team of security, browser, compiler, and platform engineers to reverse engineer the exploit, force it to trigger its payload, and understand how it worked.
During exploit contests such as pwn2own, we know ahead of time when we will receive an exploit, can convene the team ahead of time, and receive a detailed explanation of the vulnerabilities and exploit.”
Conclusion
The Firefox zero-day flaw, CVE-2024-9680, poses a significant risk due to its use-after-free vulnerability. Users are strongly urged to update to the latest versions of Firefox and Tor browsers to safeguard against potential attacks and ensure ongoing protection in today’s ever-evolving threat landscape.
