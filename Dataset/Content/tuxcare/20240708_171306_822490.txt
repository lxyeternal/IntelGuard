
Ubuntu 22.04 LTS was first released on 21 April 2021 and is supported until April 2027. The latest version of this long-term support release (5 years), Ubuntu 22.04.3 LTS, came out on August 10, 2023, with Linux kernel 6.2. However, Canonical has now rolled out a new kernel update for Ubuntu 22.04 LTS (Jammy Jellyfish), transitioning from Linux 6.2 to the more recent Linux 6.5 version. The new kernel, sourced from Ubuntu 23.10 (Mantic Minotaur), will serve as the default in the upcoming point release.

Update the Kernel in Ubuntu 22.04
Existing users with Ubuntu 22.04 installations (22.04.1, 22.04.2, or 22.04.3) can execute the command sudo apt update && sudo apt full-upgrade in the terminal to upgrade to the Linux kernel 6.5. Users of Ubuntu 22.04 LTS can now enjoy enhanced hardware support and performance improvements, thanks to the introduction of the Linux 6.5 Hardware Enablement (HWE) kernel.
Benefits of Linux Kernel 6.5
Ubuntu 22.04 LTS initially shipped with the old Linux 5.15 LTS kernel series. The new Linux 6.5, set to be the foundation for Ubuntu 22.04.4 LTS, facilitates smoother installations on contemporary hardware, providing an optimal experience for those adopting the long-term supported Jammy Jellyfish series on new computers.
This development is particularly beneficial for existing Jammy Jellyfish users, offering superior hardware compatibility and performance enhancements over the previous Linux 6.2 HWE kernel from Ubuntu 23.04 (Lunar Lobster), reaching its end of life on January 25th, 2024.
Noteworthy features in Linux kernel 6.5 include Wi-Fi 7 support, MIDI 2.0 support in ALSA, ACPI support for the RISC-V architecture, Landlock support for UML (User-Mode Linux), and improvements for AMD “Zen” systems. In addition to the kernel update, the upcoming fourth point release will incorporate all packages released since third point release, along with a more recent Mesa graphics stack (Mesa 23.2) catering to gamers.
Conclusion
Ubuntu 22.04.4 LTS is expected to be released in February 2024. It’s worth noting that while Ubuntu 22.04 LTS will continue to receive security updates until October 2026, it will be succeeded by Ubuntu 24.04 LTS (Noble Numbat) on April 25th, 2024. For those interested in downloading the latest Ubuntu 22.04 LTS with latest kernel version, you can get it on the official website.
