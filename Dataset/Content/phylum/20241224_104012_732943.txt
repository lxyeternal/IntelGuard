
Background
On June 25, 2024, Sansec issued an alert to developers regarding a serious supply-chain security incident. The CDN on the polyfill[.]io domain was found to be serving malware in a highly sophisticated manner designed to evade detection. The issue traces back to February 2024, when a Chinese company acquired both the domain and its associated GitHub account. Shortly after the acquisition, the domain began injecting malware into mobile devices via any website embedding cdn[.]polyfill[.]io. Attempts to raise concerns were actively suppressed by the new maintainers, with complaints in the polyfill GitHub repository being systematically scrubbed.
Polyfill.js is a JavaScript library designed to allow modern functionality on older browsers that don’t natively support newer features. Its purpose is to allow developers to write code using the latest standards while ensuring that their applications work seamlessly for all users, regardless of the browser they use. While highly convenient for developers, dynamically loading such content from any CDN without an SRI check in place is risky.


Open Source References to polyfill
Today, we scanned recently published packages to identify any that reference polyfill[.]io in any capacity. We discovered that the following packages include such references. It's important to note that the presence of a package on this list does not necessarily mean it is fully compromised. Instead, it indicates that the package's code contains a reference to the polyfill[.]io resource, which may be loaded under certain circumstances. If you depend on one of these packages, it is recommended to carefully check these references and understand the conditions under which they are invoked.
