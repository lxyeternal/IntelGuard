

It’s super easy to spoof Visual Studio Code extensions. And those spoofed extensions are incredibly hard to detect.
If you unwittingly install a malicious extension, bad actors can get access to your code to inject back doors, steal your credentials, drop malware or use your login to move laterally. It’s a nasty problem that’s not getting enough attention.
The same problem may also be present in Visual Studio and Azure DevOps. In this week’s Secure Software Blogwatch, we run and hide.
