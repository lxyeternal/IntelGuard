LLM 摘要分析:
The top attack patterns include remote code execution and unauthorized remote access, often implemented via backdoors, RATs, or reverse shells to gain persistent control over victim systems. Malware delivery frequently leverages social engineering vectors such as malicious macros and remote script downloads to bypass user awareness. Data theft techniques like client-side skimming, keylogging, clipboard interception, and silent screenshot capture are common for stealing sensitive information. Advanced evasion methods such as in-memory execution, multi-layer obfuscation, and API hashing help malware avoid detection and analysis. Additionally, monetization tactics like unauthorized SMS sending and ransomware-style encryption with key exfiltration are prevalent in mobile and desktop malware.

边界分析 (恶意 vs 合法的关键区别):
------------------------------------------------------------
Key differentiating factors between malicious (violated) and legitimate behaviors include:

1. Transparency and Documentation: Legitimate actions are clearly declared, documented, and have explicit user consent or permission. Malicious behaviors operate covertly, without disclosure or user awareness.

2. Purpose and Scope of Actions: Legitimate software performs actions strictly within its intended scope (e.g., declared dependencies, user-authorized data access). Malicious code performs unauthorized or unrelated actions such as opening remote shells, exfiltrating data, or executing arbitrary commands.

3. User Consent and Verification: Legitimate operations require explicit user permission or verification before accessing sensitive data or executing potentially risky actions. Malicious behaviors bypass or ignore user consent.

4. Data Handling and Privacy: Legitimate software accesses sensitive data only as necessary and never transmits it to unknown or unauthorized external servers. Malicious code exfiltrates data stealthily.

5. Absence of Coercion or Harm: Legitimate software does not threaten users, demand payments, or restrict access to their own data. Malicious software may use coercion (e.g., ransomware) or unauthorized resource usage (e.g., cryptomining).

Common patterns in malicious code violations:

- Execution of arbitrary or hidden commands (e.g., remote shells, mining parameters) unrelated to declared functionality.
- Network operations to unknown or arbitrary external servers without user knowledge.
- Use of configuration or environment files (e.g., sitecustomize.py) to inject unauthorized code.
- Accessing or exfiltrating sensitive user data without explicit permission.
- Disguising malicious payloads as legitimate files or dependencies.

Actionable guidance:
- Enforce strict documentation and declaration of all dependencies and network operations.
- Require explicit user consent for sensitive data access and execution of commands.
- Monitor environment-wide configuration files for unauthorized code.
- Detect and block network connections to unknown external servers.
- Flag any software that demands payment or restricts user data access as suspicious.

关键差异特征:
1. Malicious software executes arbitrary code from untrusted network sources, often obfuscated and decrypted at runtime; legitimate software avoids this behavior or uses transparent, documented code loading.
2. Malicious behaviors include unauthorized remote shell access, command execution, or desktop streaming without user consent; legitimate software requires explicit user authentication and consent for such actions.
3. Malicious packages may contain hidden payloads, ransom notes, or demand payment for access to user data; legitimate software never creates ransom notes or threatens users.
4. Malicious code exfiltrates sensitive data (e.g., credit card info) without user permission; legitimate software only accesses or scans sensitive data with explicit user consent and does not exfiltrate to untrusted parties.
5. Malicious software uses obfuscated, hidden, or unauthorized code execution in environment-wide configuration files (e.g., sitecustomize.py); legitimate software uses configuration files only for intended, transparent purposes.
6. Legitimate software declares dependencies transparently and documents them; malicious software hides or obfuscates dependencies and executes arbitrary local files without justification.
7. Malicious code violates security principles by embedding secrets in system prompts or performing buffer overflows; legitimate software adheres to security best practices, avoiding secrets in prompts and preventing memory corruption.
