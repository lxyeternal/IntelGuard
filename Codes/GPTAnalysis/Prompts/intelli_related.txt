1. **Specific malicious package name(s)** (e.g., "pymafka", "noblejs", "discord.dll")
2. **Analysis of malicious code or malicious behavior** of that package

**A document is RELEVANT if it contains:**

- Marketing materials or product descriptions

- ✅ RELEVANT: "The package 'pymafka' (PyPI) contains code that exfiltrates SSH keys..."
